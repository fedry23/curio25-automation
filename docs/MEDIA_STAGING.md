# Curio25: selección de 25 imágenes para revisión

La selección propone un recurso específico por cada una de las 25 curiosidades.
El workflow descarga imágenes de Wikimedia Commons a una rama aparte, genera
manifestos con SHA256, autor, licencia y página de origen, y no promueve ninguna
imagen automáticamente a data/media. El estado sigue
pending_visual_legal_review hasta que se revisen pertinencia y derechos.

Casos especiales:
- La imagen de rape abisal muestra un ejemplar de museo con macho adherido.
- La imagen del telégrafo es una textura de un modelo 3D, sustituir por una
  fotografía si no funciona en vídeo.
- La foto de 1915 del primer teléfono transcontinental es PD-US, pero deben
  verificarse derechos territoriales en España antes de explotarla.
- Los recursos CC BY-SA pueden imponer atribución, enlace a licencia e
  iguales condiciones para adaptación.
- Algunas fotos solo ilustran el tema; no certifican el número o la afirmación.
  Añadir diagramas originales con cifras de las fuentes.

El workflow NO activa YouTube ni utiliza recursos de pago.
